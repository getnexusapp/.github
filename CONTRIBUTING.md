# Contributing to Nexus

Nexus's application source is closed — this org doesn't accept pull
requests against the core app. That said, there are real, useful ways to
contribute:

## 🐛 Report a bug

Open an issue in [`getnexusapp/releases`](https://github.com/getnexusapp/releases/issues)
using the **Bug Report** template. Good bug reports include:

- Nexus version (Settings → About)
- OS and version (Windows 11, macOS 15, etc.)
- Steps to reproduce
- What you expected vs. what happened
- Screenshots or a screen recording, if relevant

## 💡 Request a feature

Also in [`getnexusapp/releases`](https://github.com/getnexusapp/releases/issues),
using the **Feature Request** template. Search existing issues first —
upvote (👍) an existing request instead of filing a duplicate; we use
reactions to help prioritize what to build next.

## 📚 Improve the docs

The [`getnexusapp/docs`](https://github.com/getnexusapp/docs) repo *is*
open to pull requests — typo fixes, clearer explanations, missing steps,
new examples. Fork it, make your change, open a PR.

## 🔒 Found a security issue?

Don't file a public issue — see
[SECURITY.md](https://github.com/getnexusapp/.github/blob/main/SECURITY.md)
for private disclosure instructions.

## 💬 Everything else

General questions, "how do I...", and open-ended discussion belong in
[Discussions](https://github.com/getnexusapp/releases/discussions), not
Issues — this keeps the issue tracker focused on actionable bugs and
requests.

Thanks for taking the time to help make Nexus better.
